# DAY. — La tua agenda

PWA personale in italiano, con interfaccia minimal bianca e nera.

## Pubblicazione su GitHub Pages
1. Carica **tutti** i file e la cartella `icons` nella radice del repository `day-agenda`.
2. In GitHub apri **Settings → Pages**.
3. In **Build and deployment** seleziona **Deploy from a branch**.
4. Seleziona il branch `principale` (oppure `main`, se è quello disponibile) e la cartella `/ (root)`, poi **Save**.
5. Attendi la pubblicazione e apri l'indirizzo GitHub Pages mostrato da GitHub.

## Installazione su iPhone
Apri il sito pubblicato in Safari → Condividi → Aggiungi alla schermata Home.

## Note importanti
- Gli impegni vengono salvati localmente nel browser/dispositivo, non sincronizzati tra dispositivi.
- Le notifiche web su iPhone hanno limitazioni e richiedono permessi; questa prima versione non garantisce notifiche affidabili se l'app è chiusa.
- La PWA può essere aggiunta alla Home, ma non può creare un vero widget iOS nativo. Per un widget nativo serve una successiva app iOS dedicata.
- I dati possono essere esportati dalla sezione Impostazioni.
